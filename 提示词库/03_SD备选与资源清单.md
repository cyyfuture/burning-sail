# 03 SD 备选工作流与资源清单 —— 本地生成路线与版权安全（T7.3.2.b / T7.2.2.a）

## 3.1 SD（ComfyUI / Forge）工作流三件

### ① 古海图 LoRA 训练建议
- **数据集**：工程2 `art/` 31 位图图标（自有）＋ 公版 Portolan 图切片（LOC/大英图书馆，见 3.2）共 60–120 张，512–768px。
- **打标**：`aged parchment map, rhumb lines, hand-drawn coast` 风格词统一； 图标类打 `icon, flat`。
- **参数起点**：rank 16 / lr 1e-4 / 8–12 epoch；过拟合征兆=海岸线复制粘贴原切片。
- **验收**：LoRA 出图与公版参照并排——"风格像、内容新"即合格。

### ② 放大工作流
- 母图 1024 → `Ultimate SD Upscale` 分块 0.5 denoise → 4x；木纹/纸纹用 `tile-controlnet` 防花。
- 立绘放大保留 `face restore（CodeFormer ≤0.5）`，过头会糊掉年代感。

### ③ 批量出图模板
- 七类种子（02 分册）逐条导出 CSV：`id, prompt, ar, seed, 用途帷幕`。
- ComfyUI `API 批量`或 A1111 `prompts from file` 跑批；出图后按 01 分册登记表回填。

### 降级判定标准（SD vs MJ）
| 类 | SD 可用性 | 判据 |
|---|---|---|
| 氛围暗图/地图装饰/物品图 | ✅ 降级可用 | 构图成立、纹理干净即可 |
| 场景插画 | ⚠️ 择优 | 群像手部崩坏 ≥2 处则弃 |
| 人物立绘/纪扉页 | ❌ 建议保 MJ | 面部结构错误 ≥2 处或衣纪关键词失效即不合格 |

## 3.3 公版古海图加工管线（T7.2.2.b）

```
LOC/BL 原图(≥2000px) → 调色(做旧统一色调: 色阶压暗角+纸纹叠加)
                     → 裁幅(按 6 海区切 24 张战术海图底: 地中海×6/北海×4/大西洋-加勒比×5/印度洋×5/东亚×4)
                     → 叠格(可选六角/方格透明层, 参数同 gridmaps 的 CELL=1.5m 换算海里)
```

- 管线脚本位置预留：`可视化工具/process_charts.py`（P8 增强，不阻塞 v1——本册先交付三步操作规程）。
- **署名规范**：每张底图右下角 8px 角标：`底图: <馆藏号> (公版) · 加工: 燃帆项目`。
