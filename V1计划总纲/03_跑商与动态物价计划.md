# 03 跑商与动态物价计划 —— 骰子＋半程序化的世界经济

> 用户需求四个关键词：**骰子+半程序化**（GM 不手算均衡，掷表驱动）、**价差还原真实历史**（锚定调研2链倍数）、**五纪演变**（物资与物价随纪改变）、**城市发展等级→建筑表单**（简洁、丰富、可博弈，含购置地产）。本部交付 `09_跑商引擎.md` 分册与 `data/prices.json`、`data/cities.json`。

## 3.1 三层物价塔（D4 展开）

### 3.1.1 L1 基价层：静态锚
- **T3.1.1.a 城市基价表**
  - 输入：调研2 289品五层链（L1产地→L5零售）＋125城库。
  - 动作：对 40 品×120 城生成"基价乘数"而非绝对价——**每品定义"产地基准价"（gAg/担）**，每城每品给档位：产地0.6 / 中转0.9 / 消费1.6 / 遥远消费2.2 / 无货（∞或奢侈品溢价4+）；档位来源＝城市产业属性（cities.json 的 industry 列，取自工程2 note 字段＋人工标注）。绝对价＝基准价×城档×纪通胀带。
  - 产出：`data/prices.json`（品×城→档）＋"一眼看懂的价差图"页（每品画一条产地→消费的价格梯，标史实倍数）。
  - 验收：明星链复算——胡椒产地→零售 6×（16 世纪上半 14–38× 垄断带、17 末 2–4× 竞争带：本表 S3 用 6×、S4 用 4×、S5 用 3×，垄断状态另由 3.2.2 派系层推高至 15–25×）；肉豆蔻班达→阿姆斯特丹"千倍孤岛"作为**事件卡专属**（常规表不出现，禁运×6 条款沿用10章）。
- **T3.1.1.b 四类城定位法**
  - 动作：GM 即兴城的快速定位法——**产地城**（问"周围种/挖/织什么"）、**中转城**（问"谁必须路过"）、**消费城**（问"谁有钱没产业"）、**孤立城**（战区/封锁：生活品翻4倍——对接12章"封锁港×5"）。四问卡片化，任何表外城市 30 秒定价。
  - 验收：用10章"港十字（物价最高）"与"盐叉湾（销赃城）"两例反测四问法。

### 3.1.2 L2 供需层：库存轨（半程序化核心）
- **T3.1.2.a 库存轨 0–5 档**
  - 动作：每城×每品一条**库存轨**（0枯竭…3常态…5饱和）。价格乘数＝基价档×库存带（0档×1.8 / 1×1.3 / 2×1.1 / 3×1.0 / 4×0.8 / 5×0.6）。轨的移动规则三来源：**玩家**（卸 N 舱→轨+N；收购 N 舱→轨−N，N≥3 才推轨——大宗才砸盘）；**系统**（季末：产地城轨+1 至自然上限、消费城轨−1 至0、中转城掷 d6 4+ 轨±1）；**事件卡**（灾疫/战争/禁运直接拨轨）。
  - 产出：库存轨页＋玩家侧"市况侦察"接口（交易 DV13＋1 舔狗式打听：GM 如实报当前档——沿用10章"探听行情"精神）。
  - 验收：模拟推演——PL 在单一消费城连抛三船胡椒（4舱×3），轨 3→5，价 ×1.0→×0.6，第三船利润 −40%——"砸盘"可复现；产地季末+1 使"卡季风集中到货"自然饱和（与2.3.2b 闭环）。
- **T3.1.2.b 库存轨的桌上呈现**
  - 动作：一城一页"市况条"（40品只列该城有交易意义的8–12品，每品：档位滑块○●○○○）；KP 面板（07部）数字化的字段即此。
  - 验收：一级48城预生成市况条；二级城仅列3–5品。

### 3.1.3 L3 行情层：玩家侧行情骰（冻结）
- **T3.1.3.a 三层乘法总式与"重掷"接口**
  - 动作：**成交价＝基准价×城档×库存带×行情骰（d6 ×0.6–2.4）**。行情骰语义升级为"当旬市况"（短期情绪），季末重掷（对接2.2.1b）；10章三条玩家动作（探听/重掷/提前反应）原样沿用，"重掷"改为"换旬蹲市"（等1旬烧日历）。
  - 验收：总式跑 10 笔随机交易，价差带宽落史实带（常态3–8×、垄断15–25×）；行情骰六档乘数与10章逐字一致。

## 3.2 派系与垄断层（价差的史实放大器）

### 3.2.1 垄断结构卡
- **T3.2.1.a 六种垄断态**
  - 动作：给可垄断品（香料系/茶/糖/军火）六态：自由竞争 / 卡特尔（价+25%）/ 特许垄断（+50%，如葡印航线 S2–S3）/ 武力垄断（VOC 征服班达型：+90% 且"垄断者暴行"事件）/ 走私渗透（PL 通道：黑市价=垄断价×0.75 但海关风险）/ 垄断崩溃（事件后 ×0.4，胡椒1627型）。垄断态挂在派系资产上（14部 faction turn 可夺取）。
  - 产出：垄断态页＋每态的 PL 玩法一段（如何挤进/打破/保住）。
  - 验收：与调研2"垄断租挤出"数据带一致（VOC 征服后价反升90% 有史实行）。

### 3.2.2 保险与信贷的跑商接口
- **T3.2.2.a 融资三件套**
  - 动作：①**bottomry 海贷**（借=船或货抵，20–36%/航次，船沉债消）；②**合股发航**（无抵押：分账份额预售，对接船份1/16制）；③**保险**（10章费率带直接 GM 化：投保动作=货值×费率，出险掷骰结算赔90%）。三者都写"谁吃违约"的剧情钩子（讨债任务→04部泛型#7）。
  - 验收：三件套样板账并入01部1.8.1 姊妹篇。

## 3.3 五纪物资演变（时间改变世界）

### 3.3.1 各纪新品解锁表
- **T3.3.1.a 商品纪门控**
  - 动作：`availability.json` 商品类目扩列——S1 常备品（香料四样/生丝/呢绒/盐/酒/粮/铜铁/珍珠）；S2＋（蔗糖规模化西传/非洲黄金/辣椒——"发现"后的新大陆品全标 S2+ 且"稀缺"态）；S3＋（马尼拉大帆船：生丝太平洋线/白银货币化/烟草入欧/可可/番茄玉米仅奇物档）；S4＋（咖啡全球化/茶叶规模化入欧/日本铜/毛皮热）；S5＋（茶-银高峰/朗姆/印花布/咖啡平民化）。**奢侈品日常化带**（调研2 U16：糖1470s −41%→1660s 再−29%、烟草 87 年 −92%、茶 1700s −51%，共同拐点 1670–1700）落成规则：S5 起旧奢侈品每十年基准价 ×0.9 递减。
  - 产出：五纪商品总表（品×纪三态）＋每纪"新货上架"事件条（进程卡联动）。
  - 验收：40 品全部门控无"万能货"（任何品至少一纪为稀缺或无）。
- **T3.3.1.b 通胀带与价格革命**
  - 动作：名义价纪通胀带（S1 0.85 / S2 1.0 / S3 1.3 / S4 1.45 / S5 1.55）＋**白银事件脉冲**（S3 中期"秘鲁白银洪峰"事件卡：一次性全球名义 +15% 且十年内回吐一半——把价格革命做成玩家看得见的一巴掌）；银铜兑换比随纪漂移条（S1 银:铜=1:90 铜贵，S5 1:110 铜贱——农民锚定银不动，铜钱零钱缩水，一句规则）。
  - 验收：通胀带与工资纪系数（1.1.2a）同源同值，无双轨。

### 3.3.2 航路纪门控
- **T3.3.2.a 航线开放表**
  - 动作：distances.json 边加 `epoch_open` 字段：好望角绕行 S2（1488 试航/1497 通航）；美洲全线 S2；麦哲伦海峡与太平洋桥 S3（1522/1565 马尼拉线）；日本锁国窗 S4（1635 后仅长崎/平户＋荷兰/中国船）；好望角—果阿常规化 S3。S1 的"欧亚"只有：地中海—亚历山大—红海陆桥／金帐汗国陆路（陆桥条款：船拆运/租船，写一页"陆桥贸易"规则——威尼斯/马穆鲁克/大明三条陆桥走廊）。
  - 验收：S1 开局任何纯海路欧亚查询被引擎拒绝；陆桥三走廊各有样板账。

## 3.4 城市发展系统

### 3.4.1 城市等级与经验
- **T3.4.1.a 发展经验公式**
  - 动作：城等级 1–6（对接工程2 tier），动态化。**城经验**季末结算＝贸易流量分（本季靠港船数×舱位）＋事件分（进程卡/PL 投资）＋区位分（航线枢纽+1）。阈值带：升一级需（当前级×3）季累积经验；**降级**事件：围城成功/大疫/河道淤塞/航线改道（史实案例行：布鲁日因安特卫普兴起而降级、里斯本 1580 后让位、安特卫普 1585 大劫）。
  - 产出：城市页卡（等级/经验条/支柱产业/建筑槽/市况条/造船级——一城一页全参数就绪）。
  - 验收：120城初始等级对表工程2 tier；模拟"PL 反复贸易的港口"10 季升 1 级（玩家能感到自己在哺育城市）。
- **T3.4.1.b 城市等级表单（建筑解锁）**
  - 动作：与01部1.7.1b 同一张表双向渲染——每级一张**表单模板**（非逐城定制）：六级城镇（3型可选）/五级（5型）/四级（8型）/三级（11型）/二级都会（13型＋S4金融类）/一级帝都（全14型＋特许）。表单保持"一页一城"极简：上半城况五行、下半建筑槽（已建打钩）。
  - 验收：表单模板共 6 张而非 120 张（简洁性红线）；建筑型四列参数只维护一处。

### 3.4.2 PL 地产与城市互动
- **T3.4.2.a 置业→城市反哺闭环**
  - 动作：PL 置业/建栈房/修灯塔给城经验+1/季每项；城市升级→PL 地产+15% 且建筑槽扩容（1.7.2b）；**市政身份**条款：房产≥2处或产业建筑≥1 → 获该城"市民"身份（本市交易免半关税/参与市政谣言网——好感度平台，接05部）。
  - 产出："市民身份"页＋三个地产生涯剧本示例（收租公/栈房主/灯塔承包人）。
  - 验收：地产收益（2.5–5%）+市民特权（关税减免）合计仍低于跑商远洋回报——钱不会自动生钱，但构成"根据地"玩法（对接调研4"母港五幕"）。

### 3.4.3 城市事件与生态
- **T3.4.3.a 城市事件 d10 表**
  - 动作：季末城经验结算时掷：1 灾疫（生存×2、劳力减半3季）/2 火灾（建筑损1）/3 丰收（粮价×0.7）/4 大市集（全城行情骰+1档）/5 新航线传闻/6 名人到访（12部NPC）/7 行会冲突（某品停售1季）/8 海盗季（港外遭遇+2）/9 王室巡视（税+奢侈消费）/10 平季。事件卡驱动库存轨与建筑——城市"活"的来源。
  - 验收：与11部进程卡（历史事件优先级更高）互斥调用不叠加。

## 3.5 跑商玩法闭环（一页流程）
- **T3.5.1.a 跑商回合卡**
  - 动作：把全流程压成一页七步卡——①情报（市况侦察/传闻）→②融资（贷款/合股/保险）→③备航（船况/补给/人手/许可）→④择窗（季风五选）→⑤航程（打包/展开）→⑥到货（市况条×行情骰成交，可分批卸货护价）→⑦分账（10章账本）。每步标"对应的规则页码"。
  - 产出：跑商七步卡（桌垫级）。
  - 验收：新手 GM 拿卡跑通"里斯本→埃尔米纳→回程"全程不翻书（卡上引用代替正文）。
