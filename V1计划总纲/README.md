## 读法

- **只想看结论**：读 00 的"核心决策记录"（D1–D14），再跳各文件末尾的"本部验收清单"。
- **要开工**：按 08 的里程碑顺序，每个任务卡都标了输入（数据源）／动作／产出（文件）／验收（可判定的标准）。
- **数据不出自本目录**：所有物价/工资/船价数字的权威源是 `调研/调研2-大航海时代物价体系/v4`（gAg 克纯银底座，2026-09-04 冻结），本目录只做设计决策与换算规则，不复制数据。
