# 00 语法与变量表 —— 文生图提示词工程总纲（T7.3.1.a）

> 统一模板语法：**`[镜头] + [主体] + [纪] + [文化区] + [环境/天气] + [风格锚] + [参数]`**
> 五变量各取一枚即成完整提示词；风格锚三档为本作审美母题（羊皮卷古图风为工程2已验证款）。

## 变量枚举表

### ① 镜头
| 枚举 | 用途 | 挂接 |
|---|---|---|
| 俯视战图 top-down battle map | 战术图手绘质感版 | C05/C06、gridmaps 上色版 |
| 斜视全景 three-quarter panorama | 港口/街区场景 | C07/C08 |
| 平视立绘 character portrait, waist-up | NPC 具名卡头像 | 14 分册名册 |
| 特写 close-up detail | 物品/文书/信物 | 清单帷幕配图 |
| 剖面图 cutaway diagram | 船舱/商馆 | 06 分册配图 |

### ② 主体（按七类目录自由组合，见 02 分册）
甲板/街市/风暴海面/酒馆内景/宫廷大厅/商队/海怪痕迹/罗盘与针路簿……主体词后**必须跟一个动作或状态**（"在卸货的""倾斜中的"），防静态证件照。

### ③ 纪（S1–S5 服装船型关键词各异）
| 纪 | 关键词带 |
|---|---|
| S1 疫火与桨帆 | late medieval, galley warship, crossbowmen, wool houppelande |
| S2 发现的代价 | age of discovery, caravel, portolan chart, landsknecht |
| S3 白银洪流 | high renaissance, galleon, ruff collar, pieces of eight |
| S4 特许公司 | dutch golden age, fluyt, porcelain trade, engraved stock certificate |
| S5 黄金时代与蒸汽前夜 | baroque navy, pirate republic, tricorn, early steam paddle |

### ④ 文化区
| 区 | 建筑/船饰关键词 |
|---|---|
| 西欧 | brick hanseatic warehouses, gothic spires |
| 地中海 | sun-bleached stone, latin sail, venetian arsenale |
| 伊斯兰 | arched souk, dhow with lateen sail, geometric tilework |
| 印度 | stepwell port, teak dhow, carved balconies |
| 东亚 | junk with battened sail, porcelain cargo, harbor pagoda |
| 美洲 | colonial fort, canoe trade, jungle coast |
| 非洲 | swahili stone town, mangrove anchorage |

### ⑤ 环境/天气
风暴五阶（distant storm clouds / rising swell / instruments failing / spray blind / eye of storm）＋ 无风带 becalmed haze ＋ 夜雾 night fog lantern glow ＋ 疫年 quarantine flags ＋ 凯旋 banners and ledger books。

### ⑥ 风格锚三档
| 档 | 关键词 | 用途 |
|---|---|---|
| **羊皮卷古图风** | aged parchment map, ink and wash, gold leaf accents | 地图/扉页/纪门控图（工程2 验证款） |
| **写实油画风** | dutch marine painting, dramatic chiaroscuro, oil on canvas | 场景插画/风暴 |
| **铜版画风** | 17th century copperplate engraving, crosshatching, monochrome | 帷幕卡头图/物品图 |

### ⑦ 参数（MJ/SD 双轨）
- **MJ**：`--ar 16:9`（场景）/`3:2`（街区）/`1:1`（立绘 token）；`--style raw` 保写实；`--s 250–500` 风格化带；`--seed <n>` 衍图锁定构图。
- **SD（ComfyUI/Forge）**：底模 realistic or 风格 LoRA；`CFG 5–7`；`steps 28–35`； Negative：`photo, modern, cars, text, watermark, jpeg artifacts`；衍图用 `img2img denoise 0.3–0.5 + inpaint 改细节`。

## 抽查自测（五组变量拼句示例）

1. `俯视战图 + 盖伦甲板接舷 + S3 + 地中海 + 风暴四阶 + 羊皮卷古图风 + --ar 16:9 --style raw`
2. `斜视全景 + 泉州桅林码头卸瓷 + S1 + 东亚 + 晨雾 + 铜版画风 + --ar 3:2`
3. `平视立绘 + 女船东持股份册 + S4 + 西欧 + 室内烛光 + 写实油画风 + --ar 1:1 --s 300`
4. `特写 + 缝线船壳与椰索 + S2 + 印度洋 + 正午 + 铜版画风 + --ar 1:1`
5. `俯视战图 + 巴扎街区追逐 + S2 + 伊斯兰 + 黄昏 + 羊皮卷古图风 + --ar 3:2`

> 每组都能读通——语法自检通过。第一批验证出图后把 seed/参数登记进 01 母图登记表。
