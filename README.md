## 已冻结的核心口径（改这里必须全书同步）

**原有六条**：

- 判定：**d20 + 属性 + 技能 ≥ DV**；难度 10/13/16/19/22
- HP = **6 + 筋骨×2**；潮汐点 3（天赋上限4）
- 炮击齐射：**DV14，3d6 船体伤害，装填2轮**
- 时间：战斗轮6秒 / 海战轮1分钟 / **航段（班次）4小时，一昼夜6段**
- 升级：里程碑 XP，每级 3 XP（9级后 4 XP），上限10级
- 士气：**0–20，起始12**；哗变骰 = 每段 d20 ≤ (6−士气)（仅士气≤5时掷）

**本轮新增（成稿时确立，改动需全书同步）**：

- **币制**：**1 银币 ≈ 5.5 克纯银**；1 金币 = 10 银币 ≈ 1 达克特；1 英镑 = 20 银币。**全期价格按克纯银折算取整，不随章节内年代漂移**（波动交由 10.2 行情骰承担）
- **编连**：**每 4 门同型炮＝1 连**，一连一骰＝3d6；余 ≤2 门伤害 +1（此式可复算出 2.2 与 2.4 的原写数值）
- **齐射递减梯**：同轮第二连 **−5**、第三连起 **−10**，**不可被任何专长移除**
- **命中五档**：险失／失手／命中／精准／重击，沿用 3.2 成功等级，**不另立新尺**
- **防御 = 13 + 护甲**；护甲同时是防御加值与伤害减免，**不拆开**
- **阵位令**：并舷3／纵队2／自由1，暗写同翻；**加成取高不叠**；旗舰沉或被俘 → 全队上限降为自由令
- **双钟追击**：6 格；每轮各至多 +1；**先满者胜，同轮双满＝双结局不重掷**；**对抗成功不推钟，改下次检定 +1 档**
- **声望与恶名分轨独立记录**，各 0–100；声望买准入，恶名买渠道
- **四货币**（XP／银币／声望／船）**互不兑换**
- **五支柱**（新规则不得使其一变为默认无趣）：**船是角色｜海是对手｜血很贵｜名声有账本｜合法性是资产**
- **技能定稿＝33 项主干＋1 项条件开放**；**补入"交易"（社交域）**；潜行归生存、攀索归操帆
